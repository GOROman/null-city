PS-14-GNのPDF自体にPS-14-KNも併記されているため、同一ファイルを重複収録していない。PS-14-DNはネジ式の図であり、差込式PS-14-Dの図とは異なる。

図面の寸法は矢印の基準面で読む。LS-55-01の33.4 mmは上側、37.1 mmは下側。今回の実物は金属ベースなしで直接取り付けているため、この37.1 mmを直接取付の実測値として扱わない。
