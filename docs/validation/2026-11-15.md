# 2026-11-15 更新版の検証

Blender 5.3.0 / Bambu Studio 02.09.01.70 / FontTools 4.68.0。

- `validate_direct_mount.py`：印刷20メッシュ水密、天板33穴、最小穴間壁4.200 mm。仮の配線突出5 mm・誤差1 mm込み床余裕2.620 mm。
- `validate_lighting.py`：3枚の1.2 mmカバーは外へ0.02 mmで非干渉、内へ0.1 mmで受け段に接触。想定LED形状のケース非干渉、配線6穴、溝裏壁1.4 mm、受け段内外の天井45°。
- `validate_usb_relief.py`：ケース・押さえの水密、ケーブル／ボタン／レバー包絡の非干渉、曲げ半径23.21 mm以上。
- `export_lighting_fit.py`：前面・側面40 mm幅のケース／カバー断片4点が水密。試験片3MFは33分31秒・11.99 g、範囲外なし、サポートなし。
- 個別標準6ジョブ・下ケース時短版・6プレート未スライス／スライス済み版の63メッシュは、正規化したSTL頂点と3MF頂点が0.00021 mm以内で一致。
- 6プレート版：20オブジェクト、PLA／TPU／半透明PLAの3材料、脚は材料2、カバーは材料3。6プレートとも範囲外なし・サポートなし。合計14時間32分51秒・513.58 g。任意キャップを除くと13時間59分30秒・497.99 g。

- README画像7枚は現行モデルから全点再描画（側面単独図を追加）。完成図・分解図は70 mmレンズの透視投影、三面図・ワイヤーフレーム・USB詳細は平行投影。ワイヤー表示にはケース・天板・受光カバー・USB押さえ・脚を使用。
- 前面マスクSVGを2回生成してバイト一致。PDFは203 × 17 mm。ロゴとマスク寸法は入力の `lighting_layout.json` から読み込む。
- フォント6形式でname ID 13/14のOFL情報、文字範囲、メトリクス、字形を検証。変更前と全アウトライン・幅・cmapが一致。ビルド2回でフォントとZIPがバイト一致。ZIPの17ファイルは配布元と完全一致しOFL全文を含む。
