# レバー取付・底面確認（Issue #4 / #5）

実物未照合。現行STL・3MFの本印刷は #4（天板）・#5（ケース）の完了まで保留する。下記は設計値の計算であり、組立保証ではない。

## 取付プレートの照合

[等倍テンプレート](MS_mount_1to1.svg)を100%・用紙に合わせる設定OFFで印刷し、100 mmの基準線を定規で確認する。現行モデルは左右40 × 前後85 mmピッチ、外形50 × 95 × 厚さ1.6 mm、M4穴φ4.5 mm。レバー中心穴はφ24 mm。

実物について、型番／基板シルクの写真、プレート外形・厚さ、左右／前後の**穴中心間**、穴径、レバー中心と穴の位置関係を記録する。「短辺42.2 mm」だけでは、外形なのか穴中心間なのか確定できない。90°回転後のコネクタ向き、スイッチ割当も確認する。`base_confirmed` は確認完了まで false を維持する。

長穴化は現物の穴中心間を測ってから行う。長辺78〜90 mmだけを可変にしても、短辺40 mmと異なるベースには対応できない。先に取付部周辺のみの印刷クーポンで4本のねじが無理なく入ることを確認する。

## 底面までの積層

| 基準（傾斜前ローカルZ） | Z / 厚さ mm | 根拠 |
|---|---:|---|
| 天板上面 | 47 | モデル |
| 天板裏面 | 43 / 天板4 | モデル |
| MSプレート上面 | 40 / スペーサー3 | JSON |
| MSプレート下面 | 38.4 / 板1.6 | 仮のMS寸法 |
| レバー本体下端 | 6.6 / MS上面から33.4下 | JSON、実物未確認 |
| ケース内底面 | 世界Z=5 | モデル、傾斜なし |

```text
天板上面 Z47 ────────── 2.55°傾斜
天板裏面 Z43 ──────────
              スペーサー 3
MS上面   Z40 ────────── ← 本体深さの基準
              MS板 1.6（33.4に重複加算しない）
              本体・コネクタ・配線
内底面 世界Z5 ────────── 水平
```

モデルと同じ回転中心Z43、角度2.55°を使うと、世界座標は
`Z = 43 + y*sin(2.55°) + (z-43)*cos(2.55°)`。
レバー中心y=18で本体下端だけを見ると床との間隔は約2.44 mm。
本体の前後寸法が未確認のため、暫定的にMS板全長95 mmを覆う下端包絡（y=18±47.5）を仮定すると、前端の最小間隔は**約0.32 mm**。これは本体がこの包絡内に収まる場合の値であり、安全な余裕とは扱わない。

```sh
python3 scripts/check_lever_clearance.py
python3 scripts/check_lever_clearance.py --half-depth 0
python3 scripts/check_lever_clearance.py --extra-depth 5 --tolerance 1
```

最後の例は、コネクタ・配線の下方突出5 mm、印刷／組立の損失1 mmを**仮定した感度計算**で約−5.67 mm（接触）となる。実測値やメーカー保証値ではない。実寸未確定なので「最悪条件でも非接触」とは結論できない。

実測時は、本体の前後左右寸法・MS上面からの深さ、接続済みハーネスの最下点／曲げ空間、M4ねじ先端・ナット・ワッシャーの最下点、LED足と絶縁後の高さをそれぞれ記録する。各部品の局所yと下端zを上式で世界Zに変換し、最小値から床Z5と誤差余裕を差し引く。ナット類は本体と異なる位置にあるため、厚さを本体深さに一括加算しない。

必要なケース高さの増分は、要求余裕をC、計算間隔をgとして、少なくとも `max(0, C-g)` mm。上フレーム延長案では天板・レバーを世界Z方向へ上げ、ねじ長・配線・傾斜接合・STL・3MFも再生成する。スペーサーを減らす案はLED足の空間を失うため、配線確認なしでは採用しない。
