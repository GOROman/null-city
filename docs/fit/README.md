# 直接取付の積層・底面クリアランス

## 実物確認済み

- 黄色い試験片は厚さ4 mm、取付穴40 × 40 mm、逃げ穴φ4.5 mm、中央穴φ24 mm。
- IMG_9783/9784で元ねじ4本による直接取付を確認。ユーザーが8方向とも擦れず動くことを確認。
- IMG_9787は32.1 mm。ユーザーが黄色い板厚込みと確認したため、板裏面からの本体突出は **28.1 mm**（32.1−4）。
- MS金属板・3 mmスペーサーは使用しない。ねじの規格は未測定で、φ4.5 mmの逃げ穴はM4指定を意味しない。

[写真確認の経緯と試験片](PHOTO_REVIEW.md)。[旧MS案の等倍図](MS_mount_1to1.svg)は比較用の旧資料で、現行の直接取付用ではない。

## 現行モデルの積層

| 基準（傾斜前のローカルZ） | Z / 厚さ mm |
|---|---:|
| 天板上面 | 47 |
| 天板裏面・本体接触面 | 43 / 天板4 |
| レバー本体下端 | 14.9 / 裏面から28.1下 |
| ケース内底面 | 世界Z=5、水平 |

```text
+Z  天板上面 Z47 ───────── 2.55°傾斜
    天板裏面 Z43 ───────── 本体直接接触
                    本体 28.1
    本体下端 Z14.9 ───────
                    配線・誤差の余裕
    内底面 世界Z5 ───────── 水平
```

モデルの回転中心Z43・角度2.55°を使い、世界座標は
`Z = 43 + y*sin(2.55°) + (z-43)*cos(2.55°)`。
レバー中心y=18での本体床間隔は約10.73 mm。前後方向95 mm（中心±47.5）の保守的な包絡を仮定した最小間隔は **8.615 mm**。
これはMS板を使用する意味ではなく、本体・配線の前後広がりを計算する仮定である。

```sh
python3 scripts/check_lever_clearance.py
python3 scripts/check_lever_clearance.py --half-depth 0
python3 scripts/check_lever_clearance.py --extra-depth 5 --tolerance 1
```

下方への配線突出5 mmと垂直方向の誤差1 mmを仮定すると最小 **2.620 mm**。要求余裕2 mmを満たす計算なので、ケース高さは維持する。配線5 mmと包絡95 mmは実測値ではない。接続後の実物がこの包絡を超える場合は再計算し、必要に応じてケースを高くする。

## LEDと残る仮組み

40 mm角の固定穴は旧半径25 mmの方向LED穴と重なるため、8個の方向LEDを半径38 mmへ移動。主ボタン・補助ボタン・レバー中心は維持する。全33貫通穴の最小壁厚は4.2 mm。

LEDパッケージの裏面突出・足の曲げ・基板やハウジングとの干渉は未確認。直接取付なのでスペーサーの隙間を前提にしない。最初の仮組みではLEDなしでレバー・ボタン・接続済みハーネスと床間隔を確認し、LEDは実部品で配置・絶縁を検証してから装着する。ボタンの締付リング、コネクタ向き、ケース締結ねじの底付きも確認する。

Issue #4の取付穴は試験片の結果を製品用天板へ反映した。Issue #5の完了条件である**ケース全体の仮組み**は未実施なので、計算だけで閉じない。

## 旧計算について

旧MS図の33.4 mmを下側の深さとした計算は誤読。公式図では33.4 mmは上側、37.1 mmは下側。この37.1 mmもMS付きの基準であり、実測した直接取付の28.1 mmと混ぜない。旧MS＋スペーサー構成は現行モデルの取付仕様ではない。
