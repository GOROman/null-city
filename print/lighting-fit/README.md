# 乳白カバー受け段の試験片

[Lighting_seat_fit.3mf](Lighting_seat_fit.3mf) は前面と右側面のケース各40 mm幅、および対応するカバー断片の計4点。CLI見積は33分33秒・11.97 g。左側面は右側面の鏡像構造。下ケース全体を印刷する前に確認する。

ケース断片は本体と同じ底面を下に、レンズ断片は厚さ1.2 mmを平置き。0.20 mm、100%直線充填、サポートなし。寸法確認用なので全点を同じPLAで印刷できる。本番はケースと半透明PLAの収縮差も確認する。

1. バリを除き、接着テープを貼らずにカバーを外側から載せる。
2. 下辺・上辺・斜辺の受けに当たり、奥へ抜けないことを確認する。
3. 軽く正面から押し、受け段が欠けたりカバーが大きくたわんだりしないことを確認する。
4. 採用LEDテープを仮置きし、前面1.5 mm・側面0.6 mmという設計隙間が実物でも残るか確認する。端子・はんだ盛りは別途逃がす。

押し込み・保持力・光学・温度は未検証。試験結果が出るまでIssue #11は閉じない。印刷は自動送信していない。
